Analise o estado atual do projeto pedagógico.

Não produza novos conteúdos.

Verifique:

1. existência da ementa;
2. disciplinas;
3. tópicos;
4. subtópicos;
5. notas produzidas;
6. notas pendentes;
7. revisão textual;
8. auditoria pedagógica;
9. questões;
10. revisão textual das questões;
11. simulados;
12. possíveis bloqueios por pré-requisitos.

Apresente:

```text

- status

DISCIPLINAS
- concluídas
- em andamento
- pendentes

NOTAS
- produzidas
- pendentes

REVISÃO TEXTUAL
- aprovadas
- pendentes
- com problemas

AUDITORIA PEDAGÓGICA
- aprovadas
- pendentes
- com problemas

QUESTÕES
- quantidade

SIMULADOS
- quantidade

PRÓXIMA ETAPA
- disciplina
- tópico
- subtópico

- nenhum ou lista de problemas
```
