Analise o estado atual do projeto pedagógico.

Não produza novos conteúdos.

Verifique:

1. existência da ementa;
2. disciplinas;
3. tópicos;
4. subtópicos;
5. notas produzidas;
6. notas pendentes;
7. auditorias;
8. questões;
9. simulados;
10. possíveis bloqueios por pré-requisitos.

Apresente o resultado nesta estrutura:

```text
PROJETO

EMENTA
- status

DISCIPLINAS
- concluídas
- em andamento
- pendentes

NOTAS
- produzidas
- pendentes

AUDITORIA
- aprovadas
- pendentes
- com problemas

QUESTÕES
- quantidade

SIMULADOS
- quantidade

PRÓXIMA ETAPA
- disciplina
- tópico
- subtópico

BLOQUEIOS
- nenhum ou lista de problemas
```

Não altere arquivos.
