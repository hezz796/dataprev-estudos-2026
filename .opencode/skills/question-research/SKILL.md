# Question Research

## Objetivo

Pesquisar questões reais de concursos e transformá-las em informação útil para aprendizagem e prática.

## Fonte

Priorize fontes públicas e confiáveis.

Exemplos:

- QConcursos;
- Gran Questões;
- PCI Concursos;
- provas oficiais;
- páginas de órgãos públicos.

## Pesquisa

A pesquisa deve partir de:

```text
disciplina
→ tópico
→ subtópico
→ banca
→ período
```

quando aplicável.

## Registro

Para cada questão relevante, registre, quando disponível:

- banca;
- ano;
- concurso;
- órgão;
- cargo;
- disciplina;
- tópico;
- subtópico;
- dificuldade;
- gabarito;
- fonte;
- referência.

Não invente metadados.

## Classificação

Cada questão deve ser identificada como:

- real;
- autoral;
- adaptada.

Nunca misture essas categorias.

## Análise

Identifique:

- assunto efetivamente cobrado;
- conceito necessário;
- palavra-chave;
- pegadinha;
- habilidade exigida;
- estratégia de resolução;
- nível de dificuldade.

## Padrões

Quando houver quantidade suficiente de questões, identifique:

- recorrência;
- formas de abordagem;
- palavras recorrentes;
- pegadinhas recorrentes;
- conceitos mais explorados.

Diferencie observação de conclusão estatisticamente sustentada.

## Reprodução

O fato de uma questão estar publicamente acessível não implica automaticamente autorização para redistribuição integral.

Quando necessário, prefira:

```text
metadados
+
referência
+
análise
+
padrão de cobrança
```

em vez de reprodução integral.

Nunca contorne restrições de acesso.

## Uso pedagógico

Os resultados podem alimentar:

```text
Writer
Question Author
Simulados
Análise de banca
```

## Princípio

Questões reais são utilizadas como evidência de cobrança.

Questões autorais são utilizadas para prática.

Uma não deve ser confundida com a outra.
