# Exam Pedagogy

## Objetivo

Integrar compreensão conceitual e estratégia de prova.

## Princípio

O aluno deve aprender:

```text
o que é
→ como funciona
→ como reconhecer
→ como aplicar
→ como a banca pode explorar
```

## Estratégia

Quando pertinente, destaque:

- palavras-chave;
- expressões decisivas;
- condições;
- exceções;
- distinções;
- confusões frequentes;
- formas de cobrança.

## Pensamento socrático

Utilize perguntas que conduzam o raciocínio:

```text
O que a questão está perguntando?
↓
Qual conceito está sendo testado?
↓
Qual palavra-chave indica isso?
↓
Qual regra se aplica?
↓
Existe exceção?
↓
Qual alternativa atende à regra?
```

Use esse processo de forma natural.

## Pegadinhas

Explique:

1. qual é a armadilha;
2. qual expressão a produz;
3. qual raciocínio está errado;
4. como identificar a armadilha em outras questões.

## Limite

Não invente características específicas de uma banca sem evidência.

Quando a banca não for conhecida, utilize estratégias gerais de interpretação.
