# Note

Uma nota representa uma unidade de aprendizagem.

## Identificação

```text
id
disciplina
tópico
subtópico
ordem
```

## Relações

```text
pré-requisitos
Wiki Links
```

## Conteúdo

A nota pode conter:

```text
contexto
conceito
explicação
exemplos
relações
aplicação
raciocínio
estratégia de prova
palavras-chave
pegadinhas
síntese
```

Nem todas as seções são obrigatórias.

A estrutura deve servir ao conteúdo.

## Metadados

Quando aplicável:

```text
dificuldade
prioridade
origem
status
```

## Princípios

A nota deve:

- respeitar a ementa;
- respeitar os pré-requisitos;
- ser compreensível;
- manter coesão com as notas relacionadas;
- utilizar recursos do Obsidian com moderação.

## Status

Quando utilizado:

```text
draft
review
approved
```
