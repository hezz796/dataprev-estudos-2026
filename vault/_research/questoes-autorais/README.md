# Questões Autorais — Prática

> **Alvo:** DATAPREV 2026 · Analista de TI — Perfil 3: Desenvolvimento de Software · Banca de referência: **FGV**

## Objetivo

Reunir **questões autorais comentadas** criadas pelo Question Author para prática, alinhadas:

- à ementa pedagógica (`vault/_system/ementa.md`);
- às notas estudadas (vault `Fase-1` a `Fase-6`);
- aos padrões de cobrança FGV (`vault/_research/questoes-reais/`).

## Política

- Questões **autorais** → prática. Questões **reais** → evidência (`questoes-reais/`). Nunca misturar.
- Questão autoral **não** é apresentada como oficial.
- Uma questão autoral pode ser *inspirada em um padrão de cobrança*, mas não copia nem parafraseia questão real.
- Sempre que possível, registrar o `padrão de cobrança` que inspirou a questão e o `tópico`/`subtópico` da ementa.
- Quando o conteúdo pertencer ao edital mas **não** houver evidência FGV, a questão é marcada como **neutra** (sem rótulo de padrão de banca).
- Não inventar origem (banca, ano, concurso).

## Estrutura

Cada arquivo cobre uma disciplina (ou núcleo de disciplina) e contém questões com:

```text
id · disciplina · tópico · subtópico · origem (autoral)
habilidade cognitiva · dificuldade · conhecimento avaliado
enunciado · alternativas (A–E) · gabarito
comentário: raciocínio · análise das alternativas · palavra-chave · pegadinha
padrão de cobrança (quando houver evidência)
```
